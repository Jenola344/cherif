# **App Name**: Cherif's Gallery

## Core Features:

- Product Gallery: Display artwork in a categorized masonry grid with hover effects and smooth transitions between sections.
- Product Details Popup: Show large product images, descriptions, size/frame selectors, and an 'Add to Cart' button in a modal.
- Shopping Cart: Store cart items with details like title, image, size, frame, quantity, and a remove option. Persist the cart during navigation.
- Checkout: Compile cart items into a message (image, title, size, frame, quantity, price, total) and redirect to an external link with the cart data as a parameter.
- Image Style Transfer: Allow users to upload an image of their room, then apply the style of a selected artwork onto it to preview how it will look.
- Product Search and Filtering: Add the capability to search and filter artworks based on category, style, and size.

## Style Guidelines:

- Primary color: Deep brown (#5A3E32) for titles, borders, and key elements.
- Secondary color: Beige (#D8C6AC) for backgrounds of sections and product cards.
- Background color: Soft-textured off-white (#F8F8F2) to provide a neutral backdrop that emphasizes the artwork and text.
- Title font: 'Playfair', a modern sans-serif similar to Didot, geometric, high contrast thin-thick lines, with an elegant, fashionable, high-end feel; If longer text is anticipated, use 'PT Sans' for body.
- Body font: 'PT Sans', a humanist sans-serif with a little warmth or personality. Pairs well with Playfair.
- Simple line icons for cart actions and navigation.
- Masonry grid layout for product gallery categories.
- Use clear and consistent spacing between elements to maintain a clean, museum-style layout.
- Subtle hover animations for product cards (slight zoom and soft shadow).
